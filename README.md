# llm-community-summarization
Experimental code for LLM-based summarization of academic communities using relational group profiling and centrality measures.

This repository contains the experimental code developed for the paper "LLM-Based Summarization of Academic Communities Using Relational Group Characterization".

The study investigates the use of Large Language Models (LLMs) to generate textual descriptions of academic communities from representative terms obtained through relational group profiling methods. It also investigates how different centrality measures can produce distinct semantic representations of the same community.
